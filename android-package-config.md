# Android package configuration

Use these values when creating the native Android wrapper in Android Studio, Capacitor, or a Trusted Web Activity.

```text
Application ID / package name: com.gauravsigmano1.rallysh
App name: Rallysh
Version name: 1.0.0
Version code: 1
Minimum SDK: 26
Target SDK: 36
Build output for Play Console: app-release.aab
```

Do not upload the HTML file, an APK, or a ZIP to Google Play for a new public app. Build and sign an Android App Bundle (`.aab`) from the native wrapper, then upload that file to Play Console.

The package name must be unique and should be checked in Play Console before committing to it.
